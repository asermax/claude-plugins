# Data flow on the canvas

The canvas's `mermaid` shape draws sequence diagrams with their labels out of place. Draw a data flow as a left-to-right flowchart instead: the components as nodes in the palette's shapes, each arrow numbered in the order of the path (`1 GET the audio`, `2 the item exists?`), and the prose naming the steps by number. Use a sequence diagram in the final document only when the document's renderer draws it correctly.
