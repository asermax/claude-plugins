# Variants in parallel

The strategy for questions several answers could settle, where only evidence picks between them.

Build two or three variants, each one an answer to the question, and race them: the same inputs, the same measure of outcome, the same rounds. The variants differ in the one dimension the question is about, nothing else. A variant that differs in polish or effort measures nothing.

Pick the winner on the evidence the race produced, and the evidence is the finding: what the winner did that the losers did not, and what each loser got wrong. A losing variant that revealed a constraint no winner could see is worth as much as the winner.

The winner's artifact becomes the reference for the real implementation. Build that implementation clean rather than extracting it from the artifact.
