# Module list on the canvas

`program-design`'s module list reference still says what the part covers, what to read before proposing it and when it fits. The record keeps the paths.

## Representation

One `mermaid` shape holding a flowchart with three subgraphs: deleted, touched and new. Each node is a file or a set of files in one folder, labelled with the path, plus the reason the file changes when the path does not make it clear. New nodes are green, touched amber and deleted red.

Under the shape, one or two lines on the placement decisions.
