# Directed mode

Used when `learn` is invoked with arguments. The user has already decided what the session should become. Do not summarize the session and do not give a take.

1. **Map the state the ask touches.** Read the skills, agents, wiki entries and local files the ask names or would change, and find every reference to them across the plugin. Report what exists, what references what, and what the ask would leave dangling.

2. **Restate each item of the ask** in your own words, as the job it does and where it lands. The user corrects the reading here, before anything is drafted.

3. **Settle what the ask leaves open** before drafting: names, scope (global or local), which existing pieces stay, which docs change. Ask these together, as questions with no preference stated. Do not decide any of them.

4. Continue with **Drafting** in `SKILL.md`, in the order the user gave the items.
