# Travelling objects

What a process moves is drawn as objects, once under each moment of the process, so the reader sees where each object is at each moment.

## Source

This pattern comes from the error-reporting one-page design, where an arrow across the screens could not show which files upload, when, and which travel inside the request instead.

## Suits

A process that runs alongside a sequence of screens, such as an upload while the user fills a form.

## On the canvas

The objects, as file shapes with their names, under each screen of a storyboard. Their drawing changes with their state: solid when packed, dashed and tilted while in flight, with a check when they arrive. An object that does not move at a screen stays solid there. Side-effect arrows join the objects under consecutive screens.
