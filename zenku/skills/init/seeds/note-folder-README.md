## What has no note yet

Honest gaps, so nobody assumes coverage that is not there. Name the part, and say where its behaviour is currently documented instead: in code comments, in an experiment's findings, or nowhere.

An omission recorded here reads as a decision. The same omission unrecorded reads as an oversight, and someone eventually writes the note twice.
