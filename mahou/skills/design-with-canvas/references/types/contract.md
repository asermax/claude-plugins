# Contract on the canvas

Draw one `mermaid` shape per member, in the form `design`'s contract type gives, each under a caption `<member> · <when it is called>` in the hand font, stacked in the order the members are called. A branch with several boundaries draws each boundary's members under that boundary's sub-branch heading. Draw no table and no separate class diagram: the braces boxes inside each flowchart carry the interfaces.
